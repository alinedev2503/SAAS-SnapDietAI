# Upwork portfolio mapping

This repository is the portfolio source for **Project C — MVP web com IA
(live AI-powered web app MVP)**.

Why this repo was chosen:

- Responsive React + TypeScript web app deployed live
- Firebase Authentication and Firestore database
- Google Gemini feature powered by `@google/genai` through a server-side proxy
- Multiple screens, dashboard, admin-style views and white-label branding
- Stripe-ready pricing and subscription structure (Advanced tier reference)

Mapping to the service tiers:

| Draft tier | Repository evidence |
|---|---|
| Prototype Live | Responsive UI, deployed homepage link |
| Working MVP | Auth + Firestore + one Gemini feature + source code |
| Full MVP | Admin views, Stripe integration, handoff documentation in `docs/` |

Do not use this repository for Projects B, D or E. Those have their own repos:

- Project B — `lead-qualifier-quote-generator`
- Project D — `ai-app-rescue-toolkit`
- Project E — `mvp-blueprint-samples`
