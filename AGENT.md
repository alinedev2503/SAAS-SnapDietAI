# Instruções para Agentes de IA — NutriLense AI

Este arquivo orienta futuros agentes e assistentes que modifiquem este repositório.

## Regras Importantes
1. Não exponha a `GEMINI_API_KEY` no frontend ou no bundle do cliente.
2. Mantenha a interface `StorageAdapter` sincronizada ao criar novas consultas de banco.
3. Não remova o suporte ao modelo Dual-Adapter (Supabase / Firebase / Local).
4. Preserve as diretrizes de acessibilidade e responsividade mobile no Tailwind CSS.
